# LLM Council: Hosted Student Success Architecture

Date: 2026-09-02  
Method: five independent advisors, anonymous peer review, chairman synthesis.

## Framed question

Where does agentic AI create measurable value, where should deterministic rules or human authority dominate, and what is the minimum credible architecture and production proof standard for the governed synthetic Student Success ecosystem?

## Independent positions

- Expansionist: use AI for cited narratives, contradiction detection, missing-evidence surfacing, approved-support suggestions, and operational insights. Keep policy and consequences outside the model.
- Contrarian: workflow is not intelligence. Limit the LLM to a cited structured mentor brief over validated evidence and approved support options. Allow one repair and replay stored artifacts without rerunning the model.
- Outsider: define a kill criterion. If AI fails to reduce review time while maintaining near-zero unsupported claims, remove it.
- First Principles: code owns validation, policy, permissions, and transitions. The LLM owns only sanitized semantic composition and critique. Measure evidence coverage, edit distance, and reviewer time.
- Execution Realist: ship one complete vertical slice. Role provisioning and evidence integrity are the real bottlenecks. Prove every boundary in production.

## Anonymous peer review

All five reviewers ranked the Execution and Contrarian proposals first or second. They agreed that online learning from mentor decisions creates hidden policy drift and must be rejected. They also agreed that support eligibility is deterministic; the LLM may explain or rank only already eligible catalogue items. Reviewers required all five roles to receive enforcement tests and clarified that the system must never send external notifications or imply causal impact from synthetic outcomes.

## Chairman verdict

Build one production-grade vertical slice:

1. Clerk identity maps server-side to a durable application role.
2. Authorized synthetic signals enter Neon through idempotent collectors.
3. Validation, deduplication, source scope, and support eligibility run deterministically.
4. A bounded LLM composes a cited mentor brief and may rank only eligible approved supports.
5. A deterministic critic rejects unsupported, uncited, or prohibited claims. One repair is allowed.
6. The workflow pauses for the assigned mentor.
7. Only explicit mentor approval creates an intervention.
8. Follow-up records delivery, completion, observations, and operational outcomes.
9. Append-only events and immutable artifacts reconstruct the historical run without silently rerunning a changed model.

Primary AI value measures: mentor review time, evidence coverage, unsupported-claim rate, critic catch rate, and mentor edit distance. Intervention completion and outcome capture measure operations, not causality.

Production proof must include signup and login, five-role denial tests, malformed-data quarantine, unsupported-claim rejection and capped repair, mentor-gated intervention creation, idempotent rerun, cross-device persistence, append-only audit verification, deterministic replay, and desktop/mobile verification against the deployed URL.
